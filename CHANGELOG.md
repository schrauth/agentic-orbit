# Changelog

## Unreleased

- The app visualizes a refusal, but no longer ships a guard: the Hooks station lights when a producer appends an `errorOccurred` line with `status: "blocked"`, and the row names the tool. The `--guard` installer option, `app/res/agentic-orbit-guard.js` and its `guard.json` are gone — policy hooks belong to the project. [Hooks for your project](docs/hooks.md) documents the event-line format, a full Copilot manifest, a minimal adapter, a scratch-file test and how a project's own `preToolUse` guard reports a denial.
- The guide stops documenting a memory count that never existed: the "What waits" list promised a `↓` under the Memory station for what a hook put in front of the model unasked, a glyph nothing draws and nothing reports — the pushed/asked split it described was removed in 0.3.0. The entry is gone, and the memory station is described with the one count it shows.
- The page's dead controls are gone, and the guide stops promising them: the shell carried a hidden button row whose zoom, fold and show buttons the page never showed — and whose handlers only re-rendered — so the row, its style rule and the page's unused minimized state are removed. The shared renderer now takes its actions as an optional argument: a surface with no controls passes none and gets no buttons, while the workshop, which has real ones, keeps them. The usage page no longer says the line's end holds buttons that zoom and fold the map; it says what the page does instead — it scales with the window, and the looks menu tunes the rest.
- A line the hook writes holds a name, not a location: the hook used to put a tool call's whole `filePath` and its whole `url` — directory tree, login, password, path and query string — into the events file, for the map that only ever drew the file's last two parts and the address's host. It now reduces both before writing: `fileTail` and `urlHost`, and a value that is not shaped like a host writes no host at all. An events file written before this still renders exactly as it did, and the privacy page lists every key a line can hold. The proxy's answer buffer is bounded at 64 KB of tail for the `usage` search, where a non-streaming answer used to be accumulated whole.
- A line the hook is still writing is no longer lost. The watcher used to read to the file's end, hand those bytes to the parser and move its offset past a half-finished line, so a write that landed in two pieces cost the map that event — and the tail of it too, since the next read began mid-line. The unfinished bytes are now held back and read again with the rest of the line, so a call that arrives in two writes still reaches the map, once.
- A child agent's own prompt no longer reads as a message from the person: every subagent instruction used to add a "new message" row to the map and clear the faults it had just collected, so a child's prompt could wipe what the main loop had reported. Now only the person's own message adds that row and clears what went wrong; a subagent's prompt leaves the board as it is. A session reset also forgets the calls the session before left open, where their ids lingered and could be closed by a later call that reused one.
- A memory server the person named is read as Memory in both MCP spellings: the nested `mcp__memory__search` and the flat `mcp_memory_search` land on the same station now, where the flat one used to fall to the network's periphery with its name alone; the classifier's comment also stops promising a `server:tool` form the parser never handled.
- The Skills tile shows which skill ran: the hook now takes the name of a `skill` call — a name, never the text the skill carried — into its line, and the map's row carries it, where before the tile could only light with the generic word. The four tool names the tile also answered to — `run_skill`, `use_skill`, `list_skills`, `search_tools` — are gone; they were relics of the repo's Claude Code days, and Copilot calls its tool `skill` alone.
- The extension retires: the browser app is the product. The core modules — the hook watcher, the event translation, the writer, the proxy, the board, the Copilot classification, the hook manifest and the drawing — moved into `app/`, and the extension package is deleted; nothing else about the map changed. One story is told everywhere now: start the host, open `http://127.0.0.1:8318`, and the live map runs beside any editor — or without one.
- Added a Fraunhofer light theme using the official Screen RGB/Hex swatches supplied from section 1.2.6 of the corporate palette guide. It is selectable in the extension, demo and standalone map; existing themes and user color overrides are unchanged.
- The proxy's telemetry rides the shared stream: what the loopback proxy measures — the model's name and its prompt tokens — is appended to the same events file the workspace hook writes, as one more compact line, and every consumer applies it through the same shared translation. The extension's map and the standalone browser map now show the same model steps, and the model's name reaches both — the standalone never saw either before, because telemetry was whichever host owned the proxy keeping it to itself. The three private copies of the model-step move — the extension's, the standalone's, the demo's — are gone; `sessionStart` now names the model on the board, so the name shows before the first proxy request.
- The map can be watched in a plain browser window, with no VS Code involved: a standalone host under `standalone/` serves the page on a loopback server and watches the same events file the extension's hook writes, so a second monitor shows the real traffic of a real session. It reads nothing else, writes nothing, and binds `127.0.0.1` only.
- The page ships as three files — an HTML shell, the drawing bundle and its styles — served by a small HTTP face that opens every connection with the setup words and the current board, then streams every new board over server-sent events; while a tool runs, a quiet one-second heartbeat keeps the connection honest.
- The host is started with one command — `--workspace` (or `--events-file`) and the page is live on port 8318 — with `--config` for the settings the extension reads, `--install-hooks` for a workspace that has none yet, and the known `--proxy`/`--proxy-port` pair for the context window.
- The page survives bad traffic: a malformed frame is skipped, a lost or broken setup frame falls back to the default words and colors, and the page reconnects on its own when the host comes back.
- The page grew a layout of its own: on a wide window the log sits beside the map with the state lines — what is running, the station counts — pinned at its foot, on a narrow one it moves under it — narrower than the window — and a slim app-style top bar, frosted and pinned, carries the live indicator and a three-bar menu button that slides out a side panel with the looks options — palette, layout, motion, pace and language — that tune the looks right on the page; the host's setup words are the starting point, the page's choice wins.
- The page's log is a rolling one, not the panel's folded feed: every call keeps its own line — timestamp, station, label, duration — appended console-style and never replaced, a running call showing its live marker until its verdict replaces the wait. The log keeps a fixed height and shell manners: it follows the newest line while you sit at the bottom and scrolls freely when you go up, and it holds the number of lines chosen in the menu — 100 by default — the oldest leaving at the top; the choice is kept for the next visit.
- The page sheds its borrowed chrome: the zoom buttons stay with the panel they belong to — in a browser the map scales with the window on its own — and the "Options" word yields to the three-bar menu button at the bar's right edge, the one shape every app's side menu wears.
- The standalone host is pinned by four test groups — the events-file name, the core's boards, the stream's opening frames and the CLI's refusals — and CI typechecks it beside the extension and the demo.
- The line under the map no longer says nothing is running while the model thinks: between the person's message and the first open call — the same state that breathes the centre — it now says the model is thinking, in every one of the seven languages, and an open call or the finished turn takes the words back. The demo says the same through the shared words, so its thinking gaps show it too.
- The root documents follow: the README tells how to start the host, the contribution guide names the third gate CI runs, and the privacy and security pages stay truthful without a new caveat — no new data is read, kept, or sent.

## 0.3.0

- The repository sheds its ballast: stale build artifacts and tool state (`.DS_Store`, an old packaged `.vsix`, the `.kiro/` directory) are gone from the working tree, and `.kiro/` is ignored so it never comes back.
- The map's options no longer carry the retired terminal renderer's settings: `textSize`, `terminalView` and `cellShape` are gone from the shared `Setup`, which now holds only what the map reads.
- The shared helpers shed four exports nothing called anymore: `firstLine` and `memoryIds` from `classify`, `taskOf` and `taskNotice` from `feed`, along with their detour through the `map` re-export hub.
- Twelve words the map never shows are gone from all seven language tables — the ones only the retired terminal panels ever read — and the tables' header no longer speaks of a manifest called `plugin.json`.
- The background-task experiment that never ran is gone: `background()`, `settle()` and every read of an `Entry.task` that no code could ever write, including the shared contract's field.
- The `map` hub that only handed its neighbors' exports on is deleted; the demo's engine now reads `shortModel` straight from `classify`.
- The `HookEvent` type no longer claims fields the hook never writes: `command` and `promptTokens` are gone; the wire format's real fields stay.
- The panel class carries the project's own name now: `LotMapPanel` is `AgenticOrbitPanel`, the last "mod" wordings say "extension", and the issue template's security link finally points at this repository instead of its terminal ancestor.
- The smoke test and the subagent storm speak English end to end, and both scripts now honor `AGENTIC_ORBIT_EVENTS_FILE` so a run never scribbles into the live event log.
- Both `tsconfig.json` files include whole directories instead of every file by name, so a new hook or source file joins the build without a config edit.
- Micro-hygiene: a stray space leaves a proxy string comparison, the file watcher's reader is a `const`, and the counts row lookup is null-checked like its siblings instead of asserted.
- The `Board` contract sheds four fields no code ever wrote — `pushed`, `open`, `minimized`, `zoom` — and the memory legend shows the plain asked-for count instead of a pushed/asked split that could never appear.
- The zoom ladder lives in one place now: `hooks/view.ts` exports the ten widths, and the panel and the demo both read them there.
- The demo's language selector reads `LANGUAGES` from the shared text module, so adding a language means adding a table — the selector follows on its own.
- Settings now reach an open map: the panel builds its setup per send instead of freezing the first one, the extension builds one per hook event, and a settings change pokes the open panel so labels and theme switch live.
- The now-line meter is built once: `hooks/view.ts` renders what `nowParts` already computes instead of rebuilding the same string with a second, subtly different model-shortening rule.
- The hooks manifest lives in its own module as named, testable data; `installHooks` just writes it, and a test pins every event's presence.

- The event → board translation lives in one shared, VS Code-free module — `vscode-extension/src/eventApplier.ts` — so the demo now replays exactly what the extension host performs, parking subagent names included; the `HookEvent` wire type moved to the shared `types` so the demo can read it without the host's Node-only watcher.

- The 634-line `hooks/draw.ts` is split into six modules under `hooks/draw/` — the geometry every drawing shares, the times things hold and fade, the effects that fly along the spokes, the crew's seats, the main loop's route, and the scene that puts it all together — with `hooks/draw.ts` itself kept as the one face the rest of the code knows. A pure move: every line of drawing logic is unchanged, and the SVG the map renders is byte-for-byte what it was.

- The demo's five hand-written scenarios — a calm turn, a storm of subagents, a subagent project, a run of errors and refusals, a context that fills up — moved into their own `demo/scenarios.ts`; the engine keeps the fake clock and the shared translation, and the demo page now reads the scenarios straight from the module that owns them.

- The extension's front door is a table of contents again: reading the settings, installing the hooks and starting the proxy each live in their own module — `config.ts`, `installHooks.ts`, `proxyCommand.ts` — and `extension.ts` is down to the wiring: the three commands, the watcher, and the state the map is drawn from.

- The proxy no longer silently truncates a request over 8 MB: bodies are buffered whole and forwarded byte-identical, deliberately — a corrupted request sent with a correct-looking `Content-Length` was the worst failure mode it could have. A new round-trip test sends nine megabytes through the proxy to a fake upstream and holds the proxy to it.

- CI now runs what the contribution rule demands: the extension job runs the full test suite instead of only compiling, and a second job typechecks the demo — the two gates this whole cleanup stands on, so a broken test or a demo/contract drift can no longer merge silently.

- The paths this cleanup touched are pinned by tests now: Copilot's tool-to-station mapping, the hook file's event parsing and its hash-name default path, the parked-name lifecycle (launch parks, oldest claim first, a failed launch hands back, the turn's end clears), the feed's row folding, and the trail's route — each case written to fail if the behavior were reverted.

- The shipped README now documents all eighteen settings, word for word as the root README has them, the root README's install line says `agentic-orbit-<version>.vsix` instead of pinning one release, and the demo paragraph names what the engine really is: the shared event translation, a made-up clock, made-up names, and the scenarios that moved to their own module.

- The webview's script ships as one self-contained bundle built by esbuild, so the panel cannot come up blank for want of a module the sandboxed webview cannot load; a guard test holds the shipped `main.js` to that: no `require`, no `import`, the message listener wired.
- The root documents catch up with the code: the privacy page no longer claims the model's name and the last opened row are kept between sessions — only the folded pane is — and the contribution guide names both gates CI enforces, the extension's tests and the demo typecheck.
- The license names a second author: the many features and fixes grown here on top of the ported engine put Manuel Schrauth beside Aleksei Volodin in the copyright lines.
- The README says at the top what this repository is: a fork and further development of an idea from another repository, the ported engine's home [lot-map](https://github.com/alexeyw/lot-map).

- The README was brought back in step with the extension as it is: the subagents' seats (five inner rings and one wide outer ring they share), the `coreName`, `background` and `colors` settings, the proxy command, and the three screenshots that had no place in it yet. What the hook pipeline does not report yet — the Browser station, the Hooks station, memory a hook brought unasked, calls that outlive their turn — now says so plainly instead of describing it as though it happened.

- The project's own agents are now part of the repository: the five generic definitions under `.github/agents/` — Architect, Builder, Memory & ADR, Reviewer and Version Control — are tracked instead of ignored, so a fresh clone carries the team that works on it.
- Real Copilot calls are paired up again: the telemetry hook now reads the call id, the tool name and the agent id from both the flat and the array shape the host sends, and takes a tool call's short description from its arguments where the host puts it. Tool rows close when their call ends instead of lingering. A spawning subagent's planet keeps its true name after all: a launch parks the description under its call id, the child's first own call claims the oldest parked name in launch order, a failed launch hands its name back, and the end of the turn clears whatever was never claimed.
- The demo grows a second long example, **Subagent project**: a made-up working session of some two and a half minutes — the main agent reading and editing between its own model steps while a dozen subagents come and go in overlapping waves, one tripping over a page that will not answer, an answer, a follow-up, and a second crew taking the orbits the first have let go of.
- Subagents keep their seat in the sky: the first five circle the five inner orbits, everyone after that shares one wide outer orbit, and no planet ever slides to another place when the crew changes. A seat only opens up again once its planet has fully faded, and the ones on the outer orbit stay there until they go — the inner ones never call them back. When more than six agents crowd the map, their hues now start cycling instead of a color being taken from a planet that is still in the sky.
- A planet no longer blinks back to full strength while it fades out: mid-fade the drawing already sits at the opacity the fade has reached, the same cure the planet's place on its orbit got.
- The orbit paths read stronger, the whole map a good tenth larger, and the Agents station sits farther out with it. The legend under the map grew with the map.
- The map moves a bit slower: pulses, ripples, the station beat and the core's breath all take a little longer.
- The **You** station is now called **Operator** — in every language the map speaks.
- New setting `agenticOrbit.pace`: with `slow`, every flight, ripple and fade on the map takes twice as long. The demo carries a pace switch of its own beside the motion one.
- A planet no longer flashes back to the top of its orbit for a frame whenever the map is redrawn: the rotation now starts from the angle the orbit is really in, so the very first frame already shows the planet where it belongs.
- A browser demo under `demo/` runs the extension's own drawing on fake events, so the map's design can be worked on and judged without packaging and installing the extension. It ships nothing and changes nothing of the extension itself.
- Subagent planets turn much slower, their orbit rings sit closer together, and a subagent that is done keeps circling for a minute before a quiet fade.
- Each subagent's planet wears a hue of its own, and a legend under the map names every color with the short description its subagent was started with. The orbit paths read firmer, the planets are a touch smaller, and while an agent works its planet pulses in its own hue — a lingering one sits still.
- A beam that leaves a subagent's planet now truly rides it along its orbit (it had clung to the wrong phase of the lap), drawn from twice as many positions so it hugs the arc, and the innermost orbit moved farther out so nothing crowds the station.

## 0.2.0

- The **Agents** station now sits far out beyond the ring of stations, and each subagent still at work circles it as a small planet in the stations' own style — one wide dashed orbit per subagent, with a ring glyph that reads the same from any side.
- The map grew with it: the drawing is larger, so the wide orbits never touch the neighbouring stations or leave the picture.

## 0.1.0

- The first release of Agentic Orbit: a VS Code extension that draws a live map of GitHub Copilot's work beside the editor — tool calls, subagents, skills and refusals as pulses between stations, with a feed of the last calls under it.
- Workspace hooks feed the map: `Agentic Orbit: Install Workspace Hooks` writes `.github/hooks/hooks.json` and the fail-safe hook script into the open project.
- An optional loopback proxy reads the token usage from your on-prem model's stream to fill the context-window ring.
- The drawing, classification and text engine was ported from the [lot-map](https://github.com/alexeyw/lot-map) project.
